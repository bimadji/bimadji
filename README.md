## Selected work

### [pos-app](https://github.com/bimadji/pos-app) · [Live demo](https://bimadji.github.io/pos-app/)

Multi-tenant dine-in POS for 10-25 table cafes with QR table ordering, atomic stock updates, live kitchen streams via Server-Sent Events, 58mm thermal receipts, and shift cash reconciliation. `FastAPI` `PostgreSQL` `Python` `React` `Tailwind CSS`

<img src="assets/work-pos.svg" alt="Denah meja, antrean pesanan kasir, dan ringkasan transaksi" width="100%">

### [LabManage](https://github.com/bimadji/LabManage) · [Live app](https://lab-manage-lilac.vercel.app)

Facility scheduling, shared vs. team hardware inventory, and weekly research attendance for the PENS Robotics Lab on Supabase Postgres with row-level security. `TypeScript` `Next.js` `React` `Supabase` `PostgreSQL`

<img src="assets/work-labmanage.svg" alt="Jadwal mingguan lab dan daftar inventaris komponen" width="100%">

### [Monocular-Distance-Estimation---YoloV8](https://github.com/bimadji/Monocular-Distance-Estimation---YoloV8)

Object distance estimation from a single webcam using YOLOv8 bounding boxes and a one-shot calibrated pinhole camera model in C++. `C++` `OpenCV` `YOLOv8`

<img src="assets/work-monocular.svg" alt="Bingkai deteksi berlabel jarak dan diagram pinhole" width="100%">
